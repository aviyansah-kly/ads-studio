# KLY Ads Studio

Homepage prototype that helps brands discover KLY advertising products by campaign objective, preview formats, compare options, and prepare a campaign brief.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```

The static production output is generated in `dist/`.

## Cloudflare Pages

- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Node.js version: `22`
