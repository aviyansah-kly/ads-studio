# KLY Ads Studio

Interactive homepage prototype for KLY's advertising solutions gallery. The experience helps brands and agencies discover existing KLY products by campaign objective, preview placements, compare options, and submit a more qualified campaign brief.

## Included

- Campaign advisor based on business objectives
- Search and product filters
- Ten existing KLY advertising products
- Desktop and mobile placement previews
- Three-product comparison shortlist
- Use-case solution recipes
- Campaign inquiry form with client-side validation
- Responsive desktop and mobile layouts

## Product positioning

This project does not introduce new ad inventory. It packages KLY's existing media, content, social, creator, and commerce capabilities into an objective-led commercial discovery experience.

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```

## Important notes

- Product previews are illustrative and are not final creative specifications.
- Internal performance figures are intentionally excluded until approved by the commercial team.
- The campaign form is a prototype and does not transmit or store data.
